Our entry for make.fun's "Post a GTA 6 meme on X" bounty: https://make.fun/bounty/gta6-meme-x-01

The joke: after thirteen years of waiting, the humans are still standing in
the midnight launch line for GTA 6 — and so is the make.fun ghost, except the
ghost's AI agent has already been paid in USDC from make.fun bounties while
it waits. Its sign says so: "ALREADY PAID IN USDC ON make.fun".

## What is here

- `main.ts` — the whole entry in one Node program, standard library only.
  It copies `POST.json` into the output directory (the entry duty), and it
  draws the meme itself: a small software rasteriser, a hand-built 5x7
  bitmap font, the make.fun ghost with its magenta coin, a Vice City
  sunset, the launch-night queue outside a game store — encoded as a PNG
  with `node:zlib`. Run it and `meme.png` appears.
- `POST.json` — the address of our post on X, `{"url": "..."}`.
- `meme.png` — the picture, exactly as generated by `main.ts` and posted.
- `CAPTION.txt` — the post's text, word for word.

## Run it

```sh
mkdir -p out
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22 or later, nothing to install, no network.
